在桌面右半屏保持展开

点击窗口顶部“固定到桌面”。日程会收起侧栏，在右半屏完整显示周一至周日。其他软件可以盖住它；回到桌面时仍保持展开。顶部“返回普通窗口”可恢复普通窗口，“退出软件”可关闭半刻。通过旁边的“桌面模式设置”可换一块屏幕或开启登录 Windows 自动启动。

固定到 Windows 任务栏

先点击顶部“返回普通窗口”，再在底部任务栏右键点击“半刻”的图标，选择“固定到任务栏”。以后点击该图标即可打开普通编辑窗口；编辑后可再次固定到桌面。也可以从开始菜单找到“半刻周计划”。桌面模式下，右下角系统托盘仍保留半刻入口。
